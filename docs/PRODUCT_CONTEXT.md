# 장비병자 — 제품 컨텍스트

> 이 문서는 ChatGPT에서 제품 아이디어와 기획을 논의할 때 사용하는 공유 맥락이다. 현재 구현에서 확인되는 사실과 앞으로 결정해야 할 가설을 구분해 기록한다.

## 한 줄 설명

전자기기 구매나 교체를 고민하는 사람이 자신의 용도, 현재 장비, 예산에 맞는 선택지를 좁히고 비교할 수 있도록 돕는 장비 진단 서비스의 초기 프로토타입이다.

## 해결하려는 문제

전자기기 구매자는 다음과 같은 어려움을 겪는다.

- 제품과 사양이 너무 많아 무엇부터 비교해야 할지 알기 어렵다.
- 자신의 사용 목적에 필요한 성능과 과한 성능을 구분하기 어렵다.
- 신제품 구매, 중고 구매, 기존 장비 업그레이드 중 무엇이 합리적인지 판단하기 어렵다.
- 본체 가격만 보고 결정했다가 렌즈, 주변기기, 호환 부품 등의 추가 비용을 놓치기 쉽다.
- 스펙표는 찾을 수 있지만, 개인 상황에 맞춰 선택지를 설명해주는 과정은 부족하다.

장비병자는 사용자가 전문 용어를 모두 알지 못해도 단계별 질문에 답하면서 후보를 좁히고, 비교와 비용 판단까지 이어지게 하는 것을 지향한다.

## 잠정 목표 사용자

아직 사용자 조사로 확정되지 않은 가설이다.

- 카메라, PC, 주변기기 등의 구매 또는 교체를 고민하는 일반 소비자
- 장비에 관심은 있지만 모든 사양과 시장 가격을 직접 조사하기는 부담스러운 사람
- 새 제품 구매와 중고 구매 사이에서 고민하는 사람
- 기존 PC의 일부만 업그레이드할지 전체를 교체할지 판단하려는 사람
- 구매 욕구가 실제 필요인지, 예산 안에서 감당할 수 있는지 확인하고 싶은 사람

## 핵심 가치 제안 가설

1. **질문으로 선택지를 좁힌다.** 사용 목적과 선호 조건을 묻고 관련 후보만 보여준다.
2. **스펙을 판단 언어로 번역한다.** 숫자 나열보다 장점, 주의점, 체감 차이를 설명한다.
3. **구매 전체 비용을 보여준다.** 신품·중고 가격뿐 아니라 호환 부품과 추가 장비 비용을 고려한다.
4. **구매하지 않는 선택도 다룬다.** 기존 장비 유지나 부분 업그레이드가 더 합리적이면 그 선택을 제안한다.
5. **결정에 필요한 비교를 한 화면에 모은다.** 후보 간 차이와 예산 도달 가능성을 쉽게 파악하게 한다.

## 현재 구현된 프로토타입

### 공통

- React와 Vite로 만든 단일 페이지 프로토타입
- 어두운 배경에 주황색과 초록색을 강조색으로 사용하는 진단 도구 형태의 UI
- 카테고리 선택 후 단계별 질문 또는 조건 필터로 진행
- 현재 카테고리: PC/컴퓨터, 카메라, 태블릿 PC, 주변기기, 미니 PC
- 태블릿 PC와 미니 PC는 준비 중 상태

### 카메라

- 똑딱이와 렌즈교환식 구분
- 유형, 브랜드, 센서 크기, 가격대, 사용 목적 필터
- 렌즈교환식에서 컴팩트 바디만 선택하는 조건
- 최대 4개 제품을 비교 목록에 추가
- 제품별 신품 참고가, 중고 참고가, 센서, 무게, 장점, 주의점 비교
- 보유 현금과 월 저축액을 이용한 간단한 구매 자금 계획
- 현재 ‘AI 비교’는 외부 AI나 API가 아니라 로컬 데이터로 만드는 시연용 비교표

### PC

- 새 PC 맞추기와 기존 PC 업그레이드 경로
- 새 PC에서는 본체만 또는 본체와 주변기기 선택 후 사용 목적 선택
- 업그레이드에서는 CPU, GPU, RAM, 저장장치, 사용 기간 입력
- 주요 부품명 자동완성 후보 제공
- 사무, 게임, 그래픽 작업, 개발 목적 선택
- 상대 성능 지수와 시연용 가격을 이용한 업그레이드 후보 및 체감 개선 시뮬레이션

### 주변기기

- 모니터, 키보드, 마우스, 헤드셋, 스피커 선택
- 각 장비에서 브랜드와 사용 목적 선택
- 선택 결과 요약까지 구현
- 실제 제품 추천과 가격 비교는 다음 단계로 남아 있음

## 아직 실제 서비스 기능이 아닌 것

- 가격과 성능 데이터는 코드에 들어 있는 시연용 값이다.
- 판매처 가격, 중고 거래 시세, 재고와 자동으로 연결되지 않는다.
- 실제 AI 모델을 호출해 개인화된 비교 결과를 생성하지 않는다.
- 사용자 계정, 진단 이력 저장, 관심 제품 저장 기능이 없다.
- 제휴 링크, 결제, 중고 거래 연결 기능이 없다.
- 추천의 객관성이나 정확도를 검증하는 데이터 파이프라인이 없다.

## 제품 원칙 제안

아래 원칙은 토론을 위한 초안이며 확정된 결정이 아니다.

- 추천보다 먼저 사용자의 상황과 목적을 충분히 묻는다.
- 비싼 제품이 아니라 사용자의 조건에 맞는 제품을 우선한다.
- 추천 이유와 추천하지 않는 이유를 함께 설명한다.
- 가격과 시세에는 기준 시점과 출처를 표시한다.
- 확실하지 않은 정보는 확실한 사실처럼 표현하지 않는다.
- 제휴나 수익 관계가 추천에 영향을 준다면 명확히 공개한다.
- 전문 사용자는 세부 조건을 조정할 수 있고, 초보자는 쉬운 질문만으로 진행할 수 있게 한다.

## 우선 논의할 제품 질문

1. 첫 번째 핵심 사용자를 누구로 좁힐 것인가?
2. 첫 번째로 완성할 카테고리는 카메라, PC, 주변기기 중 무엇인가?
3. 장비병자의 대표 가치는 ‘제품 추천’, ‘업그레이드 판단’, ‘구매 욕구 진단’, ‘예산 계획’ 중 무엇인가?
4. 사용자가 서비스를 신뢰하게 만드는 근거와 설명 방식은 무엇인가?
5. 실시간 가격과 중고 시세를 어디에서 어떤 방식으로 확보할 것인가?
6. 개인화 추천에 필요한 최소 질문은 무엇이며, 어떤 질문은 이탈을 유발하는가?
7. 수익 모델을 제휴 판매, 광고, 구독, 전문가 상담 중 어디에 둘 것인가?
8. 추천 결과가 틀리거나 가격이 오래되었을 때의 위험을 어떻게 줄일 것인가?
9. ‘장비병자’라는 이름의 유머와 친근함을 유지하면서도 구매를 부추기는 서비스로 보이지 않게 하려면 어떻게 해야 하는가?

## 당장 검증할 수 있는 가설

- 사용자는 긴 스펙표보다 자신의 목적에 맞춘 3개 안팎의 후보를 선호한다.
- 신품·중고 가격과 추가 비용을 함께 보여주면 구매 판단에 도움이 된다.
- ‘현재 장비를 유지해도 된다’는 결과가 추천 신뢰도를 높인다.
- 카메라 사용자와 PC 사용자는 필요한 질문 구조가 크게 다르므로 카테고리별 진단 흐름이 필요하다.
- 초보자용 쉬운 질문과 전문가용 세부 필터를 한 흐름에서 선택할 수 있어야 한다.

## ChatGPT와 논의할 때의 역할

ChatGPT는 다음 역할을 맡는다.

- 제품 매니저처럼 가설과 우선순위를 검토한다.
- 무조건 동의하지 말고 약한 가정, 모순, 사용자 위험을 지적한다.
- 구현 아이디어보다 먼저 사용자 문제와 검증 방법을 명확히 한다.
- 결정된 내용과 아직 열린 질문을 구분한다.
- 기능을 제안할 때 사용자 가치, 구현 난이도, 데이터 의존성, 위험을 함께 평가한다.
- 대화가 끝날 때 결정사항, 보류사항, 다음 검증 행동을 짧게 정리한다.

## ChatGPT 첫 대화용 프롬프트

아래 문장을 새 대화의 첫 메시지로 사용할 수 있다.

> 첨부한 `PRODUCT_CONTEXT.md`와 `README.md`를 이 프로젝트의 기본 맥락으로 사용해줘. 나는 장비병자의 제품 아이디어, 사용자 경험, 기능 우선순위와 사업 가능성을 함께 논의하고 싶어. 무조건 긍정하지 말고 제품 매니저이자 비판적인 공동 창업자처럼 질문해줘. 현재 구현과 앞으로의 아이디어를 구분하고, 아직 근거가 없는 내용은 가설로 표시해줘. 먼저 이 제품의 핵심 가치가 무엇인지 네가 이해한 내용을 짧게 요약한 뒤, 지금 가장 먼저 결정해야 할 질문 세 가지를 제시해줘.

## 기술 현황

- 프런트엔드: React
- 개발 도구: Vite
- 패키지 관리자: pnpm
- 현재 버전: 초기 로컬 프로토타입
- 실행 위치: `app`
- 주요 화면 구현: `장비병자_카테고리선택.jsx`

## 문서 관리 규칙 제안

- 제품 방향이 바뀌면 이 문서를 갱신한다.
- 확정된 결정과 가설을 섞지 않는다.
- 가격, 제품 목록처럼 자주 변하는 데이터는 이 문서에 고정하지 않는다.
- ChatGPT에서 중요한 결정을 내렸다면 저장소의 별도 결정 기록에 날짜와 이유를 남긴다.
