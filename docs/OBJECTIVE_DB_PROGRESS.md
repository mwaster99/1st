# Objective DB 확장 진행 기록

## 재개 순서
1. 이 문서와 `git status --short`, `git diff --stat`를 읽는다.
2. 완료 파일을 다시 만들지 않는다. `pnpm test`로 현재 상태부터 확인한다.
3. 아래 미완료 체크리스트부터 이어간다. 사용량 한도로 멈췄다면 자동 재시작하지 않는다.

## 시작 기준
- 기존 워킹트리의 디자인 복수 선택/가격 UI 변경을 보존한다.
- 시작 시 회귀 테스트 27개 통과.
- 기변 DB 바디 7, 렌즈 11; 첫 구매 구성 5; 추가 구매 바디 14.
- 무게 불일치: A7 IV 658/659g, Z6 III 670/760g (후자는 바디 단독/배터리 포함 기준 혼용).
- 구조: 객관적 canonical 제품 + 출처/필드 검증 상태 + 기존 시연 정책을 분리한 호환 계층.
- 새 제품의 체감/사진/영상 점수는 생성하지 않는다. 기존 시연 점수는 객관 DB 밖의 legacy 정책으로만 보존한다.
- 가격 단위: canonical KRW 원, 기존 엔진 newPrice/usedPrice 만원. 기존 가격은 legacy-unverified, 기준일 null. 새 가격은 근거 없으면 null.

## 제약
- 고정렌즈 카메라는 canonical에서 mount=null과 내장 렌즈 사양으로 식별한다. 교환렌즈 호환을 지어내지 않는다.
- 미검증 기존 제품/가격을 공식 검증으로 재표시하지 않는다.
- 추천 알고리즘/점수 가중치 변경은 목적이 아니다.
