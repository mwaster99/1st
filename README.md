# 장비병자

전자기기 기변을 고민하는 사람을 위한 초기 프로토타입입니다. 카테고리별 진단 흐름, 카메라 조건 필터·비교, 신품/중고 참고가와 간단한 자금 계획을 제공합니다.

## 실행

Node.js 20 이상에서 아래 명령을 실행합니다.

```bash
pnpm install
pnpm dev
```

브라우저에서 표시되는 로컬 주소(기본 `http://localhost:5173`)를 엽니다.

## 현재 범위

- 카메라 가격은 API 연동 전의 시연용 참고가입니다.
- AI 비교 버튼은 외부 키 없이 동작하는 로컬 비교표입니다.
- 실제 판매처·중고 거래 시세 및 개인 금융 데이터 연동은 아직 포함하지 않습니다.
